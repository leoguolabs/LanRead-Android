# LanRead（澜阅）Android 端到端全场景测试用例

- **被测应用**：`com.lanread.app` versionName 1.0.5（minSdk 26 / targetSdk 36）
- **测试环境**：Windows 11 + AVD `Medium_Phone_API_36.1`（API 36.1，无窗口/有窗口模式，swiftshader/host GPU）
- **验证手段**：
  1. `adb shell uiautomator dump` 与 XML 节点属性审查
  2. `adb shell screencap -p` 截图对比与视觉验收
  3. `adb shell input` 触摸（tap）、连续滑动手势（swipe）、物理按键（keyevent）
  4. Chrome DevTools 协议（`tools/devtools_eval.mjs`）针对阅读器内部 WebView 注入 JavaScript 审查 DOM、CSS 变量与选区
  5. SQLite / Room 数据库文件（`files/databases/Isla_Reader`）直接提取与 SQL 断言
- **断言依据**：`SPEC.md`（iOS 移植产品规格说明书，含精确交互时序/CSS 值/触控分区/AI Prompt 原文）+ 源码实现行为
- **用例编号规则**：模块字母-序号（如 A-01 至 K-12）。每条用例必须包含：**测试目的**、**前置条件**、**执行步骤**、**预期结果**、**规范依据**。
- **状态标记**：
  - ✅ **通过 (Pass)**：行为与规格说明书完全一致
  - ❌ **失败 (Fail)**：逻辑错误、排版错乱或导致应用崩溃
  - ⚠️ **预期缺陷/未接线 (Known Defect / Placeholder)**：记录当前实现的已知偏差或待接线占位
  - ⛔ **阻塞 (Blocked)**：前置条件不满足导致无法验证

- **测试目的**：验证首次全新安装启动后，应用能否正确展示书库空态引导视图。
- **前置条件**：全新安装或清除全部数据（`adb shell pm clear com.lanread.app`）。
- **执行步骤**：
  1. 执行 `adb shell am start -n com.lanread.app/.MainActivity`。
  2. 观察默认呈现的底部 Tab 及主屏幕内容。
- **预期结果**：
  1. 默认停留在「书库」Tab（`tab.library`）。
  2. 书架展示空态视图（居中 80pt 图标、文案「书架空空如也」「导入您的第一本电子书开始阅读之旅」）。
